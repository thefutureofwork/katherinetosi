# Katherine Tosi · Senior Education Leader & Institutional Builder

Personal professional website.

## What this is

A static multi-page site for search committees, recruiters, and school leaders: senior education leadership, multi-stakeholder partnerships, student services, inclusion, curriculum design, and academic and AI strategy across international schools and higher education. Available from July 2027.

## Setup

1. Keep all HTML pages, `menu.js`, images, and PDFs in the root of the GitHub Pages repo.
2. Enable Pages in **Settings > Pages > Deploy from a branch > main / root**.
3. The site is live. No build step, no dependencies, no framework.

## Pages

- `index.html`: homepage (hero, stat tiles: 34 years / 6 countries / 113 teachers, practice summary, timeline, credentials, contact)
- `practice.html`: how I lead, build, and teach
- `marks.html`: full career record
- `evidence.html`: student work
- `feedback.html`: student feedback
- `gallery.html`: photo gallery
- `mon-literacy.html`: Mon literacy and cultural preservation project
- `mcn-civic-learning-council.html`: MCN Civic Learning Council
- `cv.html`: printable web CV, aligned with the Canonical CV

## Fonts

Bricolage Grotesque, Vollkorn, and Sometype Mono load from Google Fonts at runtime.

## Editing content

Content lives directly in each HTML file. The Canonical CV (Master) is the source of truth for facts, dates, and credentials; update the web CV and pages to match it.
